FAQ

Pertanyaan yang sering ditanyakan

Bagaimana cara pesan?

Pilih model di katalog, klik tombol WhatsApp, lalu sampaikan model yang diminati. Detail pesanan dikonfirmasi admin lewat WhatsApp.

Apakah bisa pesan banyak untuk seragam?

Untuk jumlah banyak, silakan konfirmasi ketersediaan dan pengerjaannya ke admin lewat WhatsApp.

Apakah harga dan stok tertera di website?

Website ini berisi katalog model. Untuk harga dan ketersediaan, silakan konfirmasi ke admin lewat WhatsApp.

Bisa pilih motif atau ukuran sendiri?

Sampaikan kebutuhan motif dan ukuran ke admin lewat WhatsApp untuk dikonfirmasi.

Bisa kirim ke luar kota?

Untuk pengiriman ke luar Pekalongan, silakan tanyakan langsung ke admin lewat WhatsApp.

Bahan kemeja dan dasternya seperti apa?

Bahan tiap model bisa ditanyakan ke admin lewat WhatsApp sebelum memesan.

Pilih model, tanya bahan lewat WhatsApp

Tanya produk, layanan, atau jadwal langsung ke admin Horangi Batik Pekalongan lewat WhatsApp.
